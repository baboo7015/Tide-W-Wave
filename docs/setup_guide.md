# ⚙️ Руководство по настройке T-W-W

## 1. Установка расширения (Локально)
1. Откройте в Chrome страницу с расширениями: `chrome://extensions/`.
2. Включите переключатель **"Режим разработчика"** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **"Загрузить распакованное расширение"** (Load unpacked).
4. Выберите папку проекта `Tide-W-Wave`.
5. Расширение будет добавлено. Убедитесь, что оно включено.

## 2. Первичная настройка калькулятора
Откройте график на любой из поддерживаемых бирж (MEXC, TradingView) и нажмите **Alt+C** или кликните по иконке расширения на панели Chrome.

В верхней части калькулятора введите ваши базовые константы, которые сохранятся навсегда (до их ручного изменения):
- **Депозит:** Впишите ваш текущий торговый баланс (например, `1000`).
- **Риск %:** Установите ваш строгий риск на сделку (обычно `1%` или `2%`).
- **Плечо:** Установите плечо (например, `10` или `20`). *На риск оно не влияет*, но калькулятор точно подсчитает необходимую маржу.
- **Ком-ия % (Fee):** Впишите комиссию вашей биржи для Taker-ордеров (рыночных), если вы входите по рынку. Для MEXC это `0.05`, на TV — около `0.06`.

## 3. Режимы визуализации
Нажмите на иконку ☀️ (или 🌙) в правом верхнем углу окна калькулятора, чтобы переключить цветовую схему на темную или светлую, в зависимости от того, какой темой графика вы пользуетесь.

## 4. Разрешения и работа с Hotkeys
По умолчанию для открытия/закрытия калькулятора используется комбинация `Alt+C` (или `Option+C` на Mac). 
Если шорткат конфликтует с другой программой:
1. Перейдите по адресу: `chrome://extensions/shortcuts`
2. Найдите расширение "Tide-W-Wave Assistant".
3. Назначьте удобное для вас неконфликтное сочетание клавиш.

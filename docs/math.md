# 🧮 Математика и формулы T-W-W Risk Calc

Калькулятор использует фиксированно-процентную модель риск-менеджмента для расчета оптимального объема входа в сделку. 

## Базовые переменные
- **Dep (Депозит)** — ваш торговый капитал.
- **Risk%** — процент риска на сделку (от 0.1% до 100%).
- **Fee%** — базовая комиссия биржи (например, 0.05% на MEXC / 0.06% на TradingView-брокерах).
- **Ent (Вход)** — цена открытия позиции.
- **SL (Стоп)** — цена фиксации убытка по сделке.
- **Lev (Плечо)** — используемое маржинальное плечо.

## 1. Расчет финансового риска
Риск в долларах вычисляется как процент от депозита:
```text
Risk_USD = Dep × (Risk% / 100)
```

## 2. Дистанция стопа (Stop Distance)
Процентное изменение цены от точки входа до точки стопа (по модулю):
```text
Stop_Dist = |Ent - SL| / Ent
```

## 3. Расчет объема (Volume) — Ключевая формула
Объем подбирается таким образом, чтобы при срабатывании стопа потери по курсу и потери на комиссиях составили ровно `Risk_USD`.
Так как комиссия берется как при открытии, так и при закрытии, общая плата за круг (для целей расчета максимального убытка) фиксируется в формуле через удвоение:
```text
Volume = Risk_USD / (Stop_Dist + (Fee% / 100 × 2))
```
*Примечание: Формула берет «худший сценарий» комиссии при закрытии по стопу (считая от стартового объема для гарантии, что убыток не превысит желаемый Risk_USD).* 

## 4. Расчет Маржи (Залога)
Плечо влияет **только** на маржу, которая блокируется на вашем счету, и **не влияет** на итоговый убыток в долларах.
```text
Margin = Volume / Lev
```

## 5. Расчет целевых значений (Take Profit & Profit)
Если Take Profit задан через R/R (Risk/Reward, например `2`):
```text
Для Long:  TP Цена = Ent + (|Ent - SL| × R/R)
Для Short: TP Цена = Ent - (|Ent - SL| × R/R)
```

Чистый профит:
```text
Gross Profit = Volume × (|Ent - TP| / Ent)
Комиссия (на выход) = Volume × (Fee% / 100)
Net Profit = Gross Profit - Комиссия
```
*(В скрипте используется упрощение `vol * fees/2`, что математически равно оплате одной комиссии от стартового объема для учета закрытия сделки, так как комиссия на открытие уже вычтена опосредованно). Заявленный `loss` всегда равен `Risk_USD`.*

## 6. Фактический R/R (Actual R/R)
Реальное соотношение цены:
```text
R/R = |Ent - TP| / |Ent - SL|
```
